## 4. Stratégie des 3 Vidéos Épinglées (Pinned Posts)

Sur TikTok, les 3 premières vidéos épinglées en haut du profil sont consultées par **85% des visiteurs de profil**. Elles doivent constituer votre **tunnel de vente complet** :

```
┌───────────────────────────┬───────────────────────────┬───────────────────────────┐
│        ÉPINGLÉ #1         │        ÉPINGLÉ #2         │        ÉPINGLÉ #3         │
│     L'OFFRE CADEAU        │     LA PREUVE PAR L'ACTE  │    AUTORITÉ & ÉDUCATION   │
│  "15 LIVRAISONS & PACK"   │    "TEST EN DIRECT DU QR" │  "3 ERREURS EN E-COMMERCE"│
│  Conversion immédiate     │    Démontre le paiement   │  Règle le problème colis  │
│  du commerçant curieux    │    instantané sans stress │  arnaques / annulations  │
└───────────────────────────┴───────────────────────────┴───────────────────────────┘
```

1. **Épinglé 1 : Le Pack Bienvenue (Offre)**
   - Miniature : Fond vert émeraude, texte jaune/blanc : **« 15 COURSES OFFERTES »**.
   - Contenu : Présentation du Pack Digital Boutique (Mini-Boutique WhatsApp, QR code universel de caisse prêt-à-imprimer et Assurance Colis Sûr offerte).

2. **Épinglé 2 : Le Test du QR Code en Direct (Démo Produit)**
   - Miniature : Gros plan sur le chevalet et le smartphone : **« LE TEST DU SCAN »**.
   - Contenu : Le client scanne sur le palier, l'argent tombe instantanément sur le compte du commerçant (+25 000 F) et du livreur (+1 500 F).

3. **Épinglé 3 : Les 3 Erreurs qui tuent votre commerce (Éducatif)**
   - Miniature : Visage expressif d'une commerçante : **« 3 ERREURS FATALES »**.
   - Contenu : Évite les livreurs fantômes, les clients qui annulent à la porte, et la monnaie manquante.
